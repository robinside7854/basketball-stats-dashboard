### 1-3. 코드 문제는 아니지만 알아둘 것

- **아무도 화면을 안 열어두면 드래프트가 멈춘다.** 자동픽은 열려 있는 기기(단장·감독관)가 쏜다. 서버 혼자 진행하는 기능은 없다. 감독관 PC 한 대는 끝까지 켜 둘 것.
- **팀을 비공개로 바꾸면 포털이 "세션이 없습니다"로 보인다.** 코드 인증을 봐주지 않기 때문. 지금 미라클은 공개(is_public=true)라 괜찮다. 드래프트 전에 비공개로 바꾸지 말 것.
- **4분기 드래프트의 "지난 분기 성적"은 3분기 기록이다.** 3분기 경기가 다 기록·마감된 뒤에 드래프트를 열어야 추천이 맞는다.
- 확인했고 문제없던 것: 두 명이 동시에 픽/더블탭(DB 제약으로 차단), 시계 시작 중복, 친선전 임시팀 유입(전부 걸러짐), 감독관↔단장 권한 교차(불가), 리셋·삭제 시 소속 정리(정확), 채팅 상한.

### 3-4. 문구
