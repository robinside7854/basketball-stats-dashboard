# 미라클 리그 대시보드 점검 — 「왜 잘 안 보는가」 (2026-10-26)

코드 전체(홈·경기·박스스코어·선수·선수 카드·내 기록·스탯·팀·기록실·하이라이트·가입/로그인·공유)와
운영 DB(계정·로그인 기록·기록 입력 시각)를 보고 정리했다. 화면을 직접 열어 보지는 못했다(작업 환경에서 사이트 접속 불가).

## 0. 먼저 — 「안 본다」는 아직 측정된 사실이 아니다

- **방문 기록이 없다.** Vercel Web Analytics 꺼져 있음(API 응답 `web_analytics_not_enabled`), Speed Insights 데이터 0,
  `league_user_accounts.last_seen_at` 은 2026-08-11 에 갱신을 끊음(`auth/me/route.ts:44`). 남은 건 **로그인 시각**뿐.
- 로그인 시각(9월 이후): 9/27 1 · 10/10 1 · 10/11 1 · 10/16 2 · 10/17 5 · 10/18 2 · 10/20 1 · **10/25 11명**.
  쿠키가 30일 고정(연장 없음, `session.ts:34`)이라 **로그인 = 한 달에 한 번 강제로 다시 들어온 날**에 가깝다.
  7/26 승인 → 8/25 → 9/24 → 10/24~25 주기와 10/25 의 11명이 맞아떨어진다. 즉 "사람들이 들어오긴 하는데 얼마나 자주인지는 모른다".
- 계정 27 / 명단 47. 9월 이후 실제로 뛴 선수 29명 중 24명은 계정이 있다 → **뛰는 사람은 대부분 가입돼 있다.** 문제는 가입이 아니라 「다시 올 이유」.
- 기록은 토요일 당일 오후에 영상 보며 입력(10/17 13:07~14:55, 10/10 14:04~15:54) → 토요일 저녁엔 볼 거리가 있다. (9/5 는 5주 뒤 입력, 9/12 는 6일 뒤 — 늦으면 그 주는 아무도 안 온다.)

**→ 1순위는 측정을 켜는 것.** Vercel Analytics(무료) 한 줄 + 로그인 회원 「마지막 열람일」 다시 기록. 이게 있어야 아래 조치의 효과를 확인할 수 있다.

## 1. 근본 원인 다섯 가지 (탭을 가로지르는 것)

### A. 들어올 「계기」가 하나도 없다
- 푸시·메일·카카오·주간 요약 전부 없음. 푸시 구독 표(`migrations/070`)만 있고 `sw.js` 에 push 핸들러 0, 발송 코드 0.
- 단톡방에 링크를 던져도 **비회원은 자물쇠 화면**(`layout.tsx:77` → `PrivateLeagueGate`), 미리보기 카드 제목은 「로그인이 필요합니다」, OG 이미지는 팀명 없는 공용. 하이라이트 짧은 링크(`/h/…`)도 같은 게이트.
- 「이미지 저장」은 PNG 다운로드만(갤러리 → 카톡 3단계). `navigator.share` 는 홈 링크 복사에만 쓰임.

### B. 들어와도 「내 얘기」가 없다
- **홈**: 팀 이름 카드(화면 1/5) → 지난 토요일 팀 승패 3줄 → 「경기별 결과 보기」 **접힘** → 이번 분기 순위 → 리더. 「내 카드」는 10/14 에 뺐다. 오늘 내가 몇 점인지 홈에 숫자가 없다.
- **박스스코어**: 로그인 사용자 참조 0건(`BoxscoreContent.tsx` grep 0) — 47명 표에서 내 이름을 눈으로 찾는다.
- **스탯 탭**: 출전 30% 미만은 기본 화면에서 숨김(`stats/page.tsx:348`), 내 행 강조·고정 없음 → 가끔 나오는 회원은 자기 이름이 없다.
- **내 기록(/me)**: 첫 화면에 숫자 0 — 「내 선수 카드 열기」 버튼이 콘텐츠(`PersonalDashboard.tsx:190-205`).
- **선수 카드**: 폰 첫 화면 = 사진 160px + 소속 + 분기 칸 + 분기 칩 + 탭 2줄 → 득점 숫자는 스크롤 뒤. 가장 "내 얘기"다운 「요즘 흐름」 문장은 6번째 탭의 서브탭.

### C. 문턱이 높고 조용히 잠긴다
- 비공개 + 승인제 + 비밀번호(초기값 생년월일). 승인 대기자는 재방문해도 자물쇠만(「승인 대기중」 배지는 게이트 통과 후 컴포넌트에만 있어 **비공개 리그에선 절대 안 보임**). 승인 알림 없음.
- 가입 폼 이름 자동완성이 `GET /players` 401 로 **무력**(`LoginModal.tsx:201` ↔ `players/route.ts:16`) — 등록명 불일치면 실패.
- 쿠키 30일 만료 시 예고 없이 **전체 화면 자물쇠** → 체감 "앱이 자꾸 로그아웃됨". iOS 홈 화면 앱은 사파리와 쿠키가 달라 또 로그인.

### D. 너무 많다
- 스탯 탭: 첫 숫자까지 서브탭 3 + 분기 ≈5 + 모드 3 + 범위 2 + 정렬 칩 9 ≈ **22개 컨트롤**, 지표 33개, 용어 시트는 12항목만.
- 선수 카드: 탭 6 + 토글 5 + 분기 칩, 시즌 스탯 탭 한 장에 섹션 10개.
- 팀 탭: 한 페이지 섹션 7개, 열 이름이 영어(Basic/Shooting/Advanced, eFG%·ORtg…) — 스탯 탭은 한글화했는데 팀 탭은 그대로.
- 홈 하단 「클러치샷/마일스톤」 탭은 대부분 빈 카드인데 가장 무거운 계산(전체 이벤트 스캔).
- 운영 용어 노출: 「26.4Q·분기」「최소 N일 출전」「총 32개 날짜 등록됨」「미실시·대관 없음」「비정규」「이벤트의 team_id가 모두 비어있음」.

### E. 느리다 (주 1회 리그에 60초 캐시)
- `cachedLeagueStats`·`leagueEventIndex`·`dashboardBase` TTL 60초 → 토요일 저녁 첫 방문자마다 캐시 미스(전체 이벤트 1000행씩 페이지).
- 선수 카드 열기 = 클라 요청 6개(detail 3회 포함, `/players` 전원 명단 포함).
- 팀 탭 = 요청 11~20회 워터폴 + 스피너 두 겹. 일정 탭 = 4요청 2단(mode 판정용 호출 포함).
- `daily-boxscore` 캐시 없음, 홈 `HomeMeProvider` 와 박스스코어가 같은 날짜를 2번 계산.
- `isLeaguePrivateGated`/`getApprovedSession` 이 layout·page·metadata 에서 요청당 3~4회 DB 조회.

## 3. MVP 단계별 제안

원칙: **「토요일 저녁에 열면 10초 안에 내 얘기가 보이고, 주중에 한 번 다시 올 이유가 생긴다」** — 이게 되기 전엔 지표를 더 늘리지 않는다.

### MVP 0 — 측정 켜기 (반나절)
1. Vercel Web Analytics 켜기(대시보드 토글 + `@vercel/analytics` 한 줄). 무료.
2. `/auth/me` 호출 때 `last_seen_at` 다시 기록(하루 1회만 UPDATE) → 「이번 주 들어온 회원 N명」을 어드민 설정 화면에.
3. 2~3주 뒤 숫자로 다시 본다. (이 문서의 가설이 틀릴 수도 있다.)

### MVP 1 — 「오늘 나」 (1~2주) — 효과 가장 큼
1. **홈 맨 위에 「지난 토요일 나」 카드 1장**: 득점·리바·어시 · 내 팀 N승 N패 · 평소보다 ↑/↓ 한 줄. 재료는 이미 있는 `daily-boxscore` 응답 + `detail.form.last`. 팀 이름 헤더 카드는 뺀다.
2. **박스스코어·스탯 탭에서 내 줄 노랑 + 상단 고정** (출전 30% 미만이어도 내 줄은 보임, 「순위 자격까지 N일」).
3. **내 기록(/me) 첫 화면에 같은 카드** + 그 아래 카드 열기.
4. **쿠키 슬라이딩 + 만료 시 인라인 로그인**: `/auth/me` 에서 7일 미만이면 재발급, 만료되면 자물쇠 대신 보던 화면 위에 로그인 모달.
5. **대기자 화면**: 게이트가 `mm_signup_pending` 읽어 「승인 대기중 — 승인되면 이름/생년월일로 로그인」. 가입 자동완성은 인증 없는 이름 목록 API 로.
6. **어드민 「이번 주 요약 공유」 버튼**: 기록 마감 후 텍스트(팀 승패 · 득점왕 · 링크)를 `navigator.share` 로 단톡방에 1탭. 푸시 전까지의 임시 계기.

### MVP 2 — 「주중에 돌아오게」 (2~3주)
1. **웹 푸시**: `sw.js` push 핸들러 + 구독 API(표는 있음) + 기록 마감 시 「내 클립 N개 · 오늘 14점」 1회 발송. 설정은 /me 에 토글 하나.
2. **클립 단위 공개 링크**: 서명 토큰 `?t=` 로 그 클립 한 개만 비회원도 재생 + OG 에 「홍길동 3점 · 10/17」. 공유가 전파 효과를 갖게.
3. **하이라이트 랜딩 첫 카드 = 「내 클립 · 지난 토요일 N개 NEW」** (localStorage 마지막 열람 시각).
4. 영상은 포스터(썸네일+▶) 먼저, 탭 시 재생 — 폰 자동재생 차단 대응. 클립 끝에서 멈춤.

### MVP 3 — 덜어내기 (지속, 한 번에 한 탭씩)
1. 스탯 탭: 머리엔 분기 칩만, 모드·범위·정렬은 TOP 5 아래 한 줄 드롭다운. 기본 지표 5개(득점·리바·어시·스틸·블록). 없는 막대 범례·`ratio`·「99.00」 정리.
2. 선수 카드: 기본 탭을 「요약」(지난 경기·평균·순위·흐름 문장) 하나로, 레이더·백분위·점유율·NBA·듀오는 「더 보기」. 요청 6→2(분기 detail 1회 + career). `similar_players` 계산 삭제.
3. 팀 탭: 「팀 전적 + 팀별 선수(기본 열)」만 남기고 나머지는 「더 보기」. 열 이름을 스탯 탭과 같은 한글 한 벌로. SSR 한 번에 내려 요청 11→1.
4. 홈 하단 「클러치샷/마일스톤」 탭 → 「그날 클립 N개 ▶」 한 줄. 일정 탭은 「다음 경기 1장 + 지난 결과 목록」.
5. 운영 용어 → 「10~12월」「이번 시즌」 식 날짜 말, 운영 지표는 isEditMode 에서만.
6. 캐시: TTL 60초 → 길게(이미 `league-{id}-games` 태그가 있으니 마감 시 revalidateTag), `daily-boxscore` 에 `s-maxage`.

### MVP 4 — 문턱 낮추기 (운영진 결정 필요)
1. 공개 범위 재검토: 박스스코어·일정·순위는 비로그인 열람(코드 주석의 원래 정책), 스탯·영상만 회원. 미가입 18명과 단톡방 공유 링크가 살아난다.
2. 비밀번호 대신 초대 링크(어드민이 카톡으로 전달, 1회용) — 가입·승인·초기 비번 세 단계를 한 번에.

## 4. 운영진이 정해야 할 것
- 비공개를 유지할지(MVP 4-1). 유지하면 공유는 「클립 단위 토큰」(MVP 2-2)으로만 열린다.
- 푸시를 넣을지(MVP 2-1). 안 넣으면 어드민 공유 버튼(MVP 1-6)이 유일한 계기.
- 기록 입력을 토요일 당일로 고정할 수 있는지 — 늦은 주는 어떤 화면도 소용없다.
