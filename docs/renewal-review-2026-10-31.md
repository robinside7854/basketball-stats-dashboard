# 미라클 리그 대시보드 리뉴얼 검수 — 「간결 · 직관 · 그림 중심」 (2026-10-31)

회원 화면 전부(홈·경기·박스스코어·선수·스탯·팀·기록실·하이라이트·선수 카드·내 기록·내비게이션)를 코드로 세고,

## 0. 한 줄 결론

**버튼이 많은 게 아니라 「고르는 단계」가 많다.** 숫자 하나를 보려면 탭 → 서브탭 → 분기 → 모드 → 평균/누적 → 정렬 순으로
5번 고른 뒤 표가 나온다. 그림(링·점·막대·레이더·코트)은 이미 다 만들어져 있는데 **토글·「더 보기」 뒤에 숨어 있고**, 첫 화면은
전부 숫자 타일과 표다. 리뉴얼의 핵심은 새 차트를 그리는 게 아니라 ① 고르는 단계를 없애고 ② 숨은 그림을 첫 화면으로 올리고
③ 탭 6개를 4개로 접는 것이다.

## 2. 리뉴얼 원칙 (화면 짜기 전에 정하는 것)

1. **한 화면 = 한 줄의 고르기.** 분기 칩·모드·평균/누적·정렬 같은 고르기를 화면당 최대 1줄로. 나머지는 없애거나 ⓘ 시트 안으로.
2. **폰에서는 표를 안 쓴다.** 줄 하나 = 사진 + 이름 + 숫자 1개(+ 그림 1개). 16열 표는 PC 에서만, 그것도 「표로 보기」 뒤.
3. **숫자는 카드당 최대 3개.** 4개째부터는 그림(링·막대·점)이나 「더 보기」.
4. **그림은 이미 있는 부품만 쓴다.** `viz.tsx`(RecordBar·ResultDots·Ring·VersusBar·MarginFigure) · `charts.tsx`(Radar·MiniBar·MiniLine·Donut) ·
   HexRadar · 슛 코트 · AssistNetwork · PlayerMilestoneChart. 새 차트 라이브러리를 들이지 않는다(recharts 는 선수 카드에서 이미 뺐다).
5. **사진이 주인공.** 리더·명단·카드·하이라이트는 4:5 사진이 먼저, 이름·숫자는 사진 아래. 영상이 있는 곳은 썸네일을 깐다.
6. **설명은 ⓘ 하나로.** 인라인 안내 문장·범례·「뽑는 방법」 문단은 전부 InfoTip/시트로. 영어 약어 0.
7. **어드민 화면(기록 입력·설정·명단 편집·드래프트)은 이번 리뉴얼에서 건드리지 않는다.** 회원 화면만.

## 4. 화면별 설계안 (지금 → 바꾼 뒤)

### 4-1. 홈 — 「지난 토요일을 한 장으로」
지금: 「나」 카드(숫자 3) → 팀 승패 글자 3줄 + 접힌 경기 타일 → 이번 분기 순위표(RecordBar) → 리더 6부문×3명 글자.
바꾼 뒤(위에서부터, 폰 2화면 안):
1. **「지난 토요일 나」** — 사진 + 득점 큰 숫자 1개 + **Ring(그날 득점 순위 N/M)** + 승패 **ResultDots**. 내 클립 ▶ 썸네일 1장.
2. **그날 팀 결과** — 팀 3개를 **RecordBar 3줄**로(글자 「2승 1패 +15」 → 막대 + MarginFigure). 경기 타일은 박스스코어로 보낸다(홈에서 접힘 삭제).
3. **이번 분기 순위** — 지금 카드 그대로(이미 그림). 「상대전적」 칩 줄은 뺀다(박스스코어·경기 탭에 있음).
4. **리더 6부문** — 부문당 **1위 사진 1장 + 숫자 1개**(6칸 격자). 2·3위는 누르면 카드. 「최소 N일 출전」 문구는 ⓘ.
   컨트롤 22 → **≈10**. 지표 9 → 6.

### 4-2. 경기 — 「날짜를 누르면 그날이 한 장」
지금: 분기 칩 + 날짜 카드 10장(RecordBar·details·시간·장소·정원) + 더 보기 → 박스스코어 4탭.
바꾼 뒤:
- **일정 = 세로 타임라인**(날짜 점 + 썸네일 1장 + 팀 RecordBar 3줄). 시간·장소·정원·고정 대관은 다음 경기일 카드 하나에만. 분기 칩 삭제(스크롤).
- **박스스코어 = 탭 4 → 2(경기 · 선수)**:
  - 경기: 경기별 **VersusBar**(홈 a:b 원정, 쿼터 점수는 MiniBar) + 맞붙은 팀 **HeadToHeadBars**(지금 3번 탭을 여기로, 12줄 → 득점·리바·어시·야투율 4줄, 「더 보기」로 나머지).
  - 선수: 폰은 사진 줄(이름·득점 1개 + 리바/어시 작은 글자), 정렬 칩 6개는 **「득점 ▾」 하나**로. 16열 PC 표는 「표로 보기」 뒤.
  - 어시스트 네트워크는 「경기」 안 「더 보기」로(분석가용). 영어 헤더 0.
  - 「이날의 주인공」은 사진 크게 + 클립 ▶.

### 4-3. 선수 — 「명단과 순위가 한 화면」
지금: 선수 탭(사진 격자 + 칩 7) / 스탯 탭(TOP5 + 카드 12 + 표, 컨트롤 32~60).
바꾼 뒤(합침):
- 윗줄 토글 하나: **「순위 ▾ 득점」**(득점·리바·어시·스틸·블록·3점·출석) — 이게 유일한 고르기. 분기는 「이번 분기 / 전체」 2칩.
- 본문: **사진 4:5 격자**(지금 선수 탭 그대로)인데 카드 아래에 고른 지표 숫자 1개 + **얇은 GrowBar(1위 대비)**. 순위 자격 미달은 흐리게(숨기지 않음).
- 기본/슈팅/고급·평균/누적·용어 시트·비교 체크박스·TOP5 블록·12열 표는 **삭제**. 비교는 카드 안 「나와 비교」로 충분.
- PC 에만 「표로 보기」 링크(지금 표 그대로, 한글 열).
  컨트롤 32+분기 → **≈4**. 지표 24 → 7(+카드 안에서 전부).

### 4-4. 선수 카드 — 「첫 화면이 그림」
지금: 사진 + 분기 칸 + 액션 4 + 기간 칩 + 탭 4 → 요약 탭은 숫자 타일 6 + 토글 + 문장 + 타일, 그림은 「더 보기」 안.
바꾼 뒤:
1. 머리: 사진 + 이름 + 팀 색 띠. 액션은 ▶ 하이라이트 하나(비교·닫기는 아이콘).
2. **첫 화면 = HexRadar**(지금 「더 보기」 안) + 득점·리바·어시 3숫자. 「요즘 흐름」 한 문장은 레이더 아래.
3. 탭 4 → **3(요약 · 기록 · 플레이스타일)**. 커리어 하이는 요약 맨 아래 4칸. 기록 탭은 **추이선(GameTrendChart) 먼저**, 표는 「더 보기」.
   일별/월별/분기별 세그먼트 → 추이선 위 범위 2칩(최근 10일 / 전체).
4. 플레이스타일: 지금 그대로(이미 코트·링·NBA 사진 중심) — 코트/도넛 토글만 코트 하나로.
5. 기간 칩·순위 범위(전체/같은 포지션) 토글은 ⓘ 시트 안으로(기본은 「연 화면의 분기 · 전체」).
   버튼 17 → ≈8. 「더 보기」 섹션 10 → 4.

### 4-5. 영상(하이라이트) — 「칩 10 → 3」
- 첫 화면: **내 클립 1장 크게** + 지난 경기일 썸네일 줄(가로 스크롤) + 선수 고르기(사진 격자 시트).
- 베스트샷·명경기·마일스톤 칩은 「더 보기」 한 줄로. 명경기 「뽑는 방법」 문단 → ⓘ.
- 재생기는 지금 것 유지(10/26 포스터·클립 끝 멈춤).

### 4-6. 나 — 「내 카드 + 출석 링 + 마일스톤」
지금도 가장 그림 비중이 높다(Ring·GrowBar·썸네일). 바꿀 것은 **「내 선수 카드 열기」 버튼 → 카드 첫 화면(레이더)을 그대로 박기** 하나.
계정 카드는 톱니로.

## 6. 위험 · 비용

- **ISR Reads 79%(10/27 Usage).** R1~R4 는 캐시 항목을 늘리지 않게 기존 항목(`getCachedLeagueStats`·`daily-boxscore`·`leagueEventIndex`)만 재사용한다. 새 unstable_cache 추가는 R5 정리 뒤에.
- **10/25 「막대 없이」 결정과의 충돌** — 2절 원칙 1·3 으로 푼다(그림이 숫자를 대신할 때만). 운영진 확인 필요.
- **사진 없는 선수 9명** — 사진 중심 화면에서 이니셜 원이 섞인다. 사진 올리기를 단톡방에 한 번 요청하면 거의 해결.
- **PC 11명** — 표를 「표로 보기」 뒤로 보내면 PC 사용자가 한 번 더 누른다. 수용 가능(PC 는 1/3).
- **코드 위험**: 선수 카드 1,726줄·박스스코어 1,562줄은 통째로 다시 짜는 게 아니라 **첫 화면 순서와 탭만** 바꾼다. 계산(한 벌 원칙 — `playerTotals`·`boxLine`·`isPlusOneFor`)은 손대지 않는다.
- 어드민 기록 입력·설정·명단 편집·드래프트는 범위 밖(바뀌지 않음).

## 7. 운영진이 정해야 할 것

1. 탭 6 → 4(+나) 로 접기 — 특히 **스탯 탭을 선수 탭에 합치는 것**, 팀 탭·기록실을 없애는 것.
2. 「그림이 숫자를 대신한다」 원칙 — 10/25 「막대 없이」와의 관계를 이렇게 정리해도 되는지.
3. 폰에서 표를 안 쓰고 PC 는 「표로 보기」 뒤로 보내는 것.
4. 비교 체크박스(스탯 탭)·용어 시트·기본/슈팅/고급 모드를 없애는 것 — 고급 지표(eFG%·TS%·USG%)는 선수 카드 안에만 남는다.
5. 단계 순서(R1 홈+박스스코어부터) — 또는 선수 카드(R3)부터.
