# 미라클 3대3 미니 농구게임 — 설계안 (2026-11-13 초안)

> 상태: **설계만 했다. 코드는 아직 없다.** 「정할 것」 4가지는 2026-11-13 정해졌다(8장). 다음은 0단계(손맛 시험판).
> 가칭: **「미라클 후프스」** (이름은 바꿔도 된다)

---

## 0. 한 줄 요약

- 우리 리그 실제 기록이 그대로 **캐릭터 능력치**가 된다.
- 폰 브라우저에서 바로 하는 **3대3 반코트 농구**다. 한 판은 **5분**이다.
- 진지한 시뮬레이션이 아니라 **과장된 스킬로 웃기는 게임**이다.
- 엔진은 무료 **Phaser 4** 를 쓰고, 지금 사이트 안에 넣는다.
- 시험 기간은 로그인 없이, 나중엔 **승인 회원만** 한다.

## 1. 어떤 게임인가

### 1-1. 한 판의 흐름

1. 내 팀 3명을 고른다 (내 분기 팀 / 아무나 / 랜덤 드래프트).
2. 상대 3명이 정해진다 (컴퓨터).
3. 점프볼 → 5분 경기.
4. 끝나면 결과 카드 (MVP · 스킬 사용 · 내 선수 기록).
5. 결과 카드를 단톡방에 공유한다.

### 1-2. 규칙 (실제 농구 + 3대3 규칙 단순화)

| 항목 | 기본값 | 바꿀 수 있나 |
|---|---|---|
| 경기 시간 | 5분 (전반·후반 없음, 한 번에) | 3분 · 5분 · 7분 |
| 먼저 도달 점수 | 21점 (먼저 넣으면 바로 끝) | 11 · 21 · 없음 |
| 점수 | 2점 · 3점 (우리 리그와 같다) | — |
| 공격 시간 | 12초 (넘기면 공 넘김) | 끄기 가능 |
| 공수 전환 | 수비 리바운드·스틸 뒤엔 **3점 선 밖으로 빼야** 공격 시작 | — |
| 파울 | 없음 (우리 리그도 파울을 기록하지 않는다) | — |
| 동점 | 다음 득점 먼저 넣는 팀이 승리 | — |

- **플러스원(+1)** 은 그대로 넣는다. 우리 리그의 진짜 규칙이라 재미 요소가 된다.
  +1 선수가 넣으면 1점 더. 화면에 「+1!」 이 크게 뜬다.

### 1-3. 조작 (폰 가로 화면)

```
┌──────────────────────────────────────────┐
│ [점수판 · 남은 시간 · 공격 시간]              │
│                                          │
│              (반코트 · 3대3)               │
│                                          │
│  (●) ← 왼손 조이스틱        [스킬] [패스]    │
│                              [ 슛 ]       │
└──────────────────────────────────────────┘
```

| 버튼 | 공격할 때 | 수비할 때 |
|---|---|---|
| 조이스틱 | 이동 · 드리블 | 이동 |
| 큰 버튼 | **슛** — 누르고 있다가 떼는 타이밍 (게이지 초록 칸에서 떼면 성공률↑) | **점프** — 블록·리바운드 |
| 작은 버튼 1 | **패스** — 조이스틱 방향의 동료에게 | **스틸** |
| 작은 버튼 2 | **스킬** — 게이지가 차면 빛남 | **스킬** |

- 수비 때는 **공에 가장 가까운 내 선수로 자동 전환**된다 (직접 바꾸기 버튼은 두지 않는다 — 버튼 줄이기).
- 슛 게이지 하나로 "실력 + 능력치"가 섞인다. 능력치가 높을수록 **초록 칸이 넓다.**
- 세로 화면에서 열면 「폰을 가로로 돌려 주세요」 안내.

## 2. 기록 → 능력치 바꾸기

### 2-1. 원칙

- 숫자는 지금 사이트의 **정본 한 벌**(`computeLeagueStats` · `hexRadar.ts`)에서만 가져온다.
  게임이 따로 다시 세면 선수 카드와 게임 능력치가 어긋난다.
- 능력치 = **리그 안 순위(백분위)** 를 **40~99** 로 펼친 값이다.
  (1위 = 99, 꼴찌 ≈ 40. 꼴찌도 게임은 할 만하게)
- **적게 뛴 선수 보정**: 출전일이 적으면 리그 중간값 쪽으로 당긴다.
  예) 3일 뛴 선수가 3점 10개 중 6개 → 바로 99가 되지 않게.
  식: 보정 비율 = 출전일 ÷ (출전일 + 8). 중간값 16일이면 약 2/3 만 반영.
- 기준 기간 = **이번 시즌 전체** (분기마다 팀이 바뀌어도 사람의 실력은 이어진다).
- 실측(2026-11-13): 3일 이상 뛴 선수 36명 · 출전일 중간값 15.5일 · 야투율 중간값 34%.
  비교할 사람이 충분하다.

### 2-2. 능력치 10개

| 능력치 | 어디서 오나 (실제 기록) | 게임에서 하는 일 |
|---|---|---|
| **3점** | 3점 성공률 + 하루 3점 성공 수 | 3점 게이지 초록 칸 폭 |
| **중거리** | 미드레인지(`shot_2p_mid`) 성공률 | 중거리 게이지 |
| **골밑** | 레이업·포스트 성공률 + 성공 수 | 골밑 슛·덩크 성공률 |
| **패스** | 어시스트 점유율 (레이더 리딩 축) | 패스 속도 · 받는 사람 슛 보너스 |
| **볼 지키기** | 턴오버율 (낮을수록 높게) | 상대 스틸에 잘 안 뺏김 |
| **스틸** | 하루 스틸 | 스틸 성공률 · 손 뻗는 범위 |
| **블록** | 하루 블록 | 블록 범위 · 점프 높이 |
| **리바운드** | 리바운드 점유율 (공격·수비) | 튄 공에 끌리는 힘 |
| **스피드** | 속공 득점 + 스틸 (뛰는 선수일수록) + 포지션 | 달리기 속도 |
| **체력** | **출전일 수** (자주 나온 사람 = 체력왕) | 스킬 게이지 차는 속도 |

- **키**(`league_players.height_cm`, 전원 실측값 있음)는 캐릭터 크기·점프에 그대로 쓴다.
- **포지션**(G·F·C)은 체형과 기본 동작(가드 = 빠른 드리블 / 센터 = 몸싸움)을 정한다.
- **종합(OVR)** 은 화면에만 보이는 숫자다. 경기 계산엔 쓰지 않는다.

### 2-3. 캐주얼 균형 — 능력치가 전부가 아니게

- 능력치 99 와 50 의 **노마크 슛 성공률 차이는 65% vs 45% 정도**로 묶는다.
  잘하는 사람 캐릭터가 이기기 쉽지만, 조작을 잘하면 뒤집힌다.
- 컴퓨터 상대는 쉬움 · 보통 · 어려움 3단계.

### 2-4. 이번 주 컨디션 (재미 장치)

- 지난 경기일 기록이 시즌 평균보다 좋았으면 **🔥 컨디션 +3**, 나빴으면 **🥶 −3**.
- 매주 토요일 경기 뒤 바뀐다. "이번 주 OO 캐릭터 쓰자"는 이야깃거리가 생긴다.

## 3. 스킬과 선수 특징 (실제 농구와 거리가 먼 것)

### 3-1. 구조

- 선수마다 **필살기 1개 + 특성 1개**.
- 필살기는 **그 선수 가장 높은 능력치**로 자동으로 정해진다.
- 특성은 **운영진이 재미로 붙인다** (단톡방 별명·버릇 같은 것). 비워 두면 자동.
- 스킬 게이지는 득점·어시스트·스틸·블록으로 찬다. 꽉 차면 [스킬] 버튼이 빛난다.

### 3-2. 필살기 예시 (가장 높은 능력치 → 필살기)

| 1위 능력치 | 필살기 | 효과 |
|---|---|---|
| 3점 | **불꽃 손** | 5초간 공에 불이 붙고 3점 무조건 초록 칸 |
| 3점 (2호) | **하프코트 미사일** | 코트 끝에서 쏴도 3점 판정 · 공이 로켓처럼 날아감 |
| 골밑 | **지진 덩크** | 덩크 순간 화면이 흔들리고 주변 상대가 넘어짐 |
| 패스 | **투명 패스** | 공이 1초간 사라졌다가 동료 손에 나타남 (가로채기 불가) |
| 스틸 | **시간 정지** | 2초간 상대 전원 멈춤 · 그 사이 공 뺏기 |
| 블록 | **거미손** | 손이 길어져 3초간 모든 슛을 막을 수 있음 |
| 리바운드 | **자석** | 튄 공이 무조건 내게 날아옴 |
| 스피드 | **순간이동** | 바라보는 방향으로 짧게 순간이동 |
| 볼 지키기 | **분신술** | 분신 2개가 생겨 상대가 진짜를 못 찾음 |
| 체력 | **무한 질주** | 5초간 속도 2배 · 우리 팀 게이지도 조금 채움 |

### 3-3. 특성 예시 (늘 켜져 있는 작은 효과)

- **플러스원** — 진짜 +1 선수. 넣으면 1점 더 (리그 규칙 그대로).
- **팀장 왕관** — 그 분기 팀장. 같은 팀 동료 능력치 +2.
- **다이나믹 듀오** — 실제 기록에서 서로 어시스트를 가장 많이 주고받은 두 사람이 같은 팀이면 합체기 「앨리웁 쇼」가 열린다. (선수 카드의 듀오 재료를 그대로 쓴다)
- **바나나 껍질** — 스틸당하면 그 자리에 껍질을 남겨 쫓아오는 상대가 미끄러짐.
- **잔소리꾼** — 가까이 있는 상대의 슛 게이지가 흔들림.
- **기복왕** — 매 슛마다 성공률이 크게 오르거나 크게 내려감.
- **출석왕** — 올해 출석 1위. 경기 마지막 1분에 능력치 +5.

### 3-4. 보이는 모습

- **큰 머리 · 작은 몸 캐릭터**. 머리는 그 선수의 실제 프로필 사진을 귀엽게 바꾼 그림.
- 유니폼 = **그 달 우리 팀 유니폼 색**(노랑·흰색·검정, 지금 DB 에 있음).
- 등번호 = 실제 등번호.

## 4. 유명 농구게임에서 가져올 것 / 안 가져올 것

> 게임의 **방식(규칙·조작 아이디어)** 만 참고한다. 이름·캐릭터·그림·음악·화면 모양은 베끼지 않는다.

| 게임 | 가져올 것 ✅ | 안 가져올 것 ❌ |
|---|---|---|
| **NBA Jam** (아케이드 2대2) | 3연속 성공 → 「불붙음」 상태 · 큰 머리 모드 · 말도 안 되는 높이의 덩크 · 짧은 판 | 2대2 (우리는 3대3) |
| **NBA Street** (길거리 3대3) | 기술을 쓸수록 차는 **필살기 게이지** · 3대3 반코트 · 「21점 먼저」 | 복잡한 기술 조합 버튼 |
| **3on3 FreeStyle** (온라인 3대3) | 포지션마다 다른 역할 · 선수별 스킬 세트 | 뽑기·유료 강화 |
| **Basketball Stars** (모바일) | **한 손가락 슛 타이밍 게이지** · 3~5분 판 | 1대1 구성 |
| **Hoop Land** (모바일 픽셀 농구) | 픽셀 그림으로도 충분히 재밌다는 것 · 능력치가 플레이에 진짜로 드러나는 방식 | 시즌 경영 모드 (너무 큼) |
| **Mario Hoops 3-on-3** | 캐릭터마다 과장된 필살 슛 · 아이템 같은 장난 | 아이템 상자 (스킬로 대신) |
| **Brawl Stars** (모바일 3대3) | **왼손 조이스틱 + 오른손 큰 버튼** · 캐릭터마다 확실히 다른 개성 · 3분 판 · 끝나고 결과 카드 | 상자 뽑기·과금 |
| **NBA 2K** | 선수 능력치 카드 보여 주는 방식 (OVR + 세부) | 진지한 시뮬레이션·복잡한 조작 전부 |

**결론: 「NBA Jam 의 과장 + NBA Street 의 게이지 + Brawl Stars 의 폰 조작」** 조합이 목표에 가장 가깝다.

## 5. 만드는 도구 추천

### 5-1. 반드시 쓰는 것 (모두 무료)

| 용도 | 도구 | 왜 |
|---|---|---|
| 게임 엔진 | **Phaser 4** (MIT, 무료) | 폰 브라우저 2D 게임의 표준. 2026년 4월 정식판. 자료가 가장 많다 |
| 조이스틱 | rexrainbow 플러그인 (무료) | Phaser 용 가상 조이스틱이 이미 있다 |
| 공 궤적 | 직접 계산 (높이 값 하나 추가) | 위에서 비스듬히 본 코트라 진짜 물리엔진보다 가볍고 조절이 쉽다 |
| 효과음 | **jsfxr · ChipTone** (무료) | 「띠용」「쾅」 같은 게임 소리를 바로 만든다 |
| 무료 그림·소리 | **Kenney.nl** (CC0 — 출처 표시도 필요 없음) | 코트·공·버튼·효과음 묶음 |
| 시험 | Playwright (이미 있음) | 폰 화면 크기로 자동 점검 |

### 5-2. 그림 (퀄리티를 가장 크게 좌우)

| 도구 | 가격 | 추천 |
|---|---|---|
| **제미나이 이미지 생성** | 이미 연결돼 있음 | ⭐ 선수 **얼굴 → 큰 머리 캐릭터 얼굴** 만들기. 유니폼 사진 네 벌 만들 때 이미 써 봤다 |
| **Aseprite** | 약 2만 7천 원, **한 번만 결제** | ⭐ 픽셀 그림·움직임 편집의 표준. 살 가치가 있다 (무료 대안: LibreSprite·Piskel) |
| **PixelLab** (AI 픽셀 움직임) | 한 달 약 1만 2~1만 6천 원 | ⭐ **유료 시험 추천.** 캐릭터 한 장으로 달리기·슛·덩크 동작을 만들어 준다. 그림 손이 가장 많이 드는 부분을 줄인다. **한 달만 써 보고** 계속할지 정한다 |
| Spine (뼈대 움직임) | 약 10만 원~ | ❌ 이 규모엔 과하다 |

- 추천 방식: **몸통은 모두 같은 기본 캐릭터 1벌**(PixelLab 으로 동작 제작) + **머리만 선수마다 다르게**(제미나이).
  36명 × 동작 10개를 따로 그리지 않아도 된다.

### 5-3. 음악

- 무료: Pixabay 음악 · OpenGameArt.
- 유료 시험: **Suno** (한 달 약 1만 4천 원) — 「미라클 리그 주제가」 같은 우리만의 노래가 가능하다. 필수는 아니다.

### 5-4. 나중에 (대전 모드)

- 실시간 대전은 어렵다(통신 지연 처리). 1차엔 넣지 않는다.
- 하게 되면 **Colyseus**(무료, 직접 운영) 또는 지금 쓰는 **Supabase Realtime**.

## 6. 어디에, 어떻게 만드나

### 6-1. 위치 — 지금 사이트 안

- 주소: `/league/<동호회>/<리그>/game` (리그 화면 안의 새 칸).
- 장점: 선수 데이터·회원 로그인·배포를 그대로 쓴다. 따로 서버가 필요 없다.
- 게임 코드는 **게임 화면을 열 때만 내려받는다** (기존 화면이 느려지지 않게).

### 6-2. 데이터 흐름

```
실제 기록 (league_game_events)
   ↓  computeLeagueStats · hexRadar (정본 한 벌)
능력치 계산 (lib/game/ratings.ts — 새로 만듦, 순수 함수)
   ↓  GET /api/leagues/[id]/game/roster   ← 캐시 1회 (ISR 읽기 1회 원칙)
게임 (폰 안에서만 돌아감 — 서버 부담 없음)
   ↓  (나중) 결과 저장 POST /game/results
순위표 · 결과 공유
```

- 능력치는 **매주 토요일 기록이 마감되면** 저절로 바뀐다 (기존 캐시 태그를 같이 씀).
- 경기 계산은 전부 폰 안에서 한다. 서버 비용은 거의 늘지 않는다.

### 6-3. 로그인 단계

| 단계 | 누가 할 수 있나 | 방법 |
|---|---|---|
| 시험 기간 | 링크 받은 사람 | **비밀 주소**(아무도 못 맞히는 긴 주소 + 기한) — 로그인 없음 |
| 정식 | **승인 회원만** | 지금 있는 회원 확인(`getApprovedSession`) 한 줄로 바꾼다 |

⚠ **주의**: 미라클은 **비공개 리그**다. 로그인 없는 시험판엔 실제 이름·사진·기록이 나온다.
링크가 단톡방 밖으로 나가면 누구나 보게 된다. 그래서 아래 「정할 것 ②」 를 먼저 정해야 한다.

## 7. 만드는 순서

| 단계 | 기간(어림) | 결과물 | 확인 방법 |
|---|---|---|---|
| **0. 손맛 시험판** | 1~2주 | 네모 캐릭터 · 코트 · 조이스틱 · 슛 게이지 · 컴퓨터 상대 | 폰으로 해 보고 "조작이 재밌나"만 본다 |
| **1. 우리 선수 넣기** | 1~2주 | 능력치 계산 · 선수 고르기 · 필살기 6종 · 5분 경기 · 결과 카드 · 비밀 주소 | 운영진 몇 명이 시험 |
| **2. 꾸미기** | 2~3주 | 큰 머리 캐릭터 · 유니폼 색 · 효과음·음악 · 나머지 스킬·특성 | 단톡방 시험 공개 |
| **3. 회원 전용 + 기록** | 1주 | 로그인 전환 · 전적 저장 · 주간 순위 · 결과 공유 그림 | 정식 공개 |
| 4. (선택) 대전 | 미정 | 친구와 실시간 대전 | 1~3단계 반응 보고 결정 |

- **0단계에서 재미가 없으면 그림에 돈을 쓰지 않는다.** 손맛이 먼저다.

## 8. 정한 것 (2026-11-13 운영진)

1. **첫 상대는 컴퓨터.** 실시간 대전은 4단계.
2. **시험판은 비밀 주소 + 기한 2주 + 단톡방에서만 공유.**
3. **유료 도구 시험 의사 있음** — PixelLab 한 달 + Aseprite, 2단계(꾸미기) 시작 때 결제.
4. **필살기·특성은 운영진이 정한다.** 초안은 기록으로 자동으로 만든다(아래 8-2).
   - ⚠ 이 저장소는 **공개 저장소**다. 선수 이름이 든 초안·운영진 메모는 저장소에 넣지 않는다.
     비공개 페이지(claude.ai 아티팩트 「미라클 후프스 선수 카드」, 운영진만 열림)에 두고, 메모는 그 페이지의 저장소(`notes/<p01…>`)에 쌓인다.

### 8-1. 서버·배포 — 지금 Vercel 프로젝트 그대로 (추천)

| 선택지 | 비용 | 판단 |
|---|---|---|
| **지금 Vercel Pro 프로젝트 안 `/game`** | 추가 0원 (이미 월 $20) | ⭐ 추천. 선수 데이터·회원 로그인·자동 배포를 그대로 쓴다. 게임은 폰 안에서 돌아가 서버 일이 거의 없다. Pro 는 전송량 월 1TB 포함 |

| itch.io (비밀번호 페이지) | 무료 | 순수 시험판만. 우리 기록과 연결이 안 돼 1단계부터는 못 쓴다 |

- 비밀 주소 = `/league/<동호회>/<리그>/game?t=<토큰>`. 토큰은 해시로 표에 저장하고 기한을 둔다(`league_upload_tokens` 와 같은 방식). 기한이 지나면 회원 확인으로 바꾼다.
- 게임 데이터 API 는 **캐시 읽기 1회**(ISR Reads 원칙).
- 게임 코드는 그 화면에서만 내려받는다(다른 화면 속도 그대로).

### 8-2. 능력치 초안 식 (실제로 돌려 본 것)

- 대상: 2026 시즌 정규전 · 외부 팀 제외 · 게스트 제외 · 3일 이상 출전(36명).
- 성공률은 리그 평균으로 당겨서 센다: (성공 + 50 × 리그 성공률) ÷ (시도 + 50).
- 하루 평균 수는 리그 평균으로 당긴다: (합계 + 12 × 리그 하루 평균) ÷ (출전일 + 12).
- 슛 능력치 3개(3점·중거리·골밑) = 성공률 순위와 하루 성공 수 순위의 평균을 다시 순위로.
- 볼 지키기 = 턴오버 ÷ (야투 시도 + 0.44 × 자유투 시도 + 턴오버), 낮을수록 높게.
- 스피드 = 스틸 순위와 포지션(가드 1 · 포워드 0.5 · 센터 0)의 평균.
- 체력 = 출전일 순위.
- 점수 = 40 + 59 × 순위 백분위. 그다음 **15일 미만 출전은 55점 쪽으로 당긴다**(× 출전일 ÷ 15). 8일 미만은 「잠정」 표시.
- 필살기 = 체력을 뺀 9개 중 가장 높은 능력치. 같은 능력치가 1위인 사람이 여럿이면 능력치 높은 순서로 3가지 필살기를 돌려 준다(겹침 줄이기).
- 특성 초안 = 플러스원 · 서로 어시스트 1위인 짝(다이나믹 듀오) · 출석 상위 3명(출석왕) · 두 번째 능력치의 작은 효과.
- ⚠ 1단계에서 이 식을 `lib/game/ratings.ts`(순수 함수)로 옮길 때 숫자는 `computeLeagueStats` 결과에서 받는다 — 이벤트를 다시 세지 말 것(「선수 숫자는 한 벌」).
