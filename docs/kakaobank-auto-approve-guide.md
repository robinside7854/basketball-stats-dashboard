# 카카오뱅크 입금 → 충전 자동 승인 설정 안내

미라클 통장 주인의 **안드로이드 폰**에서 한 번만 설정하면 돼요. 설정에는 10분쯤 걸려요.
(아이폰은 다른 앱의 알림을 읽을 수 없어서 이 방법을 쓸 수 없어요.)

## 어떻게 움직이나요

1. 회원이 앱에서 충전 요청(입금자명·금액)을 보내고 통장으로 입금해요. 입금이 먼저여도 괜찮아요(48시간 안).
2. 통장 주인 폰에 카카오뱅크 「입금 50,000원 홍길동…」 알림이 와요.
3. 폰의 자동화 앱이 그 알림 글을 온볼로 보내요.
4. 온볼이 **입금자명과 금액이 딱 맞는 충전 요청 하나**를 찾아 자동으로 승인해요(보너스 포함).
   - 짝이 없거나, 같은 이름·같은 금액 요청이 둘 이상이면 승인하지 않아요 → 지금처럼 어드민이 손으로 승인.
   - 출금 알림·같은 알림 두 번은 무시해요.

## 1단계 — 온볼에서 연결 비밀번호 만들기 (어드민)

1. 미라클 앱 → 월렛 → **어드민** 탭 → 맨 아래 **「카카오뱅크 입금 자동 승인」** 펼치기
2. **「연결 비밀번호 만들기」** 누르기
3. 노란 칸에 나온 **받는 주소**와 **비밀번호**를 복사해 통장 주인에게 보내기
   - ⚠ 비밀번호는 이 화면을 닫으면 다시 볼 수 없어요. 잃어버리면 「비밀번호 새로 만들기」로 다시 만들면 돼요(옛 비밀번호는 바로 막혀요).
   - ⚠ 비밀번호는 단톡방에 올리지 마세요. 통장 주인에게 1:1로만.

## 2단계 — 카카오뱅크 알림 켜기 (통장 주인 폰)

1. 카카오뱅크 앱 → 전체 → 설정 → 알림 → **입출금 알림 켜기**
2. 폰 설정 → 알림 → 카카오뱅크 → 알림 허용, **잠금 화면에서 내용 숨기기 끄기**

## 3단계 — MacroDroid 설치·설정 (통장 주인 폰)

1. Play 스토어에서 **MacroDroid** 설치(무료 — 매크로 5개까지 무료라 충분해요)
2. 처음 열 때 **알림 접근 권한** 허용
3. **매크로 추가** 누르기

**트리거(언제)**
- 「기기 이벤트」 또는 「알림」 → **알림 수신**
- 앱 고르기: **카카오뱅크**
- 글 내용: **포함 → `입금`**

**동작(무엇을)**
- 「웹 연결」(또는 「연결」) → **HTTP 요청**
  - 방식: **POST**
  - URL: 1단계에서 받은 **받는 주소** 붙여 넣기
  - 머리글(헤더) 추가: 이름 `x-bank-token`, 값 = 1단계의 **비밀번호**
  - 본문(내용) 유형: **text/plain**
  - 본문: 옆의 「…」(매직 텍스트) 버튼으로 **알림 제목**과 **알림 내용**을 차례로 넣기
    (보통 `{not_title} {notification}` 처럼 들어가요)

**저장** → 매크로 이름은 「온볼 충전」처럼 아무거나.

4. 폰 설정 → 배터리 → MacroDroid → **배터리 최적화 안 함 / 제한 없음**
   (이걸 안 하면 폰이 잠든 사이 알림을 못 보내요)

## 4단계 — 시험하기

1. 어드민 본인이 미라클 앱에서 **1,000원 충전 요청**(입금자명 = 실제로 보낼 이름)
2. 미라클 통장으로 1,000원 입금
3. 1분 안에 충전 요청이 「완료」가 되면 성공
4. 월렛 어드민 → 「카카오뱅크 입금 자동 승인」 → **최근 받은 알림**에 「자동 승인」이 찍혀 있는지 확인
   - 「짝 없음」이면: 입금자명이 요청과 다르게 찍혔거나 금액이 달라요. 알림 글을 보고 맞춰 주세요.
   - 아무것도 안 찍히면: MacroDroid 설정(주소·비밀번호·배터리)을 다시 확인해 주세요.

## 문제가 생기면

- 폰이 꺼져 있거나 MacroDroid 가 멈춰도 **돈이 잘못 들어가는 일은 없어요** — 그동안은 자동 승인이 안 될 뿐이고, 어드민이 손으로 승인하면 돼요.
- 자동 승인을 끄려면: 월렛 어드민 → 「자동 승인 끄기」.
- 폰을 바꾸면: 새 폰에 3단계를 다시 하고, 1단계에서 비밀번호를 새로 만드는 것을 권해요.
