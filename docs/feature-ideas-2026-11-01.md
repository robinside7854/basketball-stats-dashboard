# 미라클 신기능 아이디어 — 「쌓인 기록으로 관심 끌기」 (2026-11-01)

운영진 요청: 미라클에서 기록하는 데이터를 활용해 유저들의 관심을 끌 신기능 아이데이션.
전제(운영진 결정): 비공개 리그 · 푸시 알림 없음 · 들어올 계기는 어드민의 단톡방 공유 · 경기별 MVP 는 넣지 않는다 · 배지 제도 폐지.

## 쓸 수 있는 재료 (정규전 기준 실측)

| 재료 | 양 | 뜻 |
|---|---|---|
| 기록 이벤트 | 약 2.2만 건, **전부 영상 시각·쿼터 있음** | 모든 장면이 클립이 된다 |
| 스틸 ↔ 턴오버 짝 | 스틸 1,414건 중 **1,099건**에 「누구에게서」가 있다 | 「누가 누구를 털었나」 |
| 같은 두 사람 사이 스틸 5회 이상 | **43쌍**, 최다 13회 | 천적 관계가 실제로 있다 |
| 어시스트 짝 | 성공 슛의 약 70%, 한 쌍 최다 **83회** | 케미 |
| 블록 | 352건(막은 슛 짝 찾기 88%) | 누구의 슛을 막았나 |
| 경기일·로테이션 | 38일 · 하루 9경기 승자 잔류 | 「왕좌」 연승 |
| 분기마다 팀 재편 + 드래프트 | 4분기 | 드래프트 성적표 |
| 출석·사진 | 사진 47명 중 37명 | 카드·공유 이미지 |

부족한 것: 교체 기록이 거의 없어(57건) **출전 시간·+/-·라인업 분석은 못 한다.** 파울도 3건뿐.

## 추천 순서

1. **천적 · 먹잇감 (1)** — 데이터가 이미 있고, 가장 「얘기하고 싶은」 숫자. 선수 카드 플레이스타일 탭에 한 칸.
2. **왕좌 기록 (3) + 마일스톤 예고 (4)** — 홈에 한 줄씩, 토요일 전후 방문 계기.
3. **분기 리캡 카드 (2)** — 4분기 끝(12월)에 맞춰. 회원이 단톡방에 퍼 나르는 구조.

## 운영진 확인이 필요한 것

- 「천적」 표현이 회원 사이에 불편하지 않은지(놀림 수위). 대안 이름: 「단골 상대」.
- 10번 「기록 도장판」이 폐지한 배지 제도와 겹치는지.
- 9번 승부 예측은 새 DB 표(투표)가 필요 — 마이그레이션 동의.
