# 스탯 탭 하위 구조 재편 설계 (2026-09-28)

## 배경

리그 「스탯」 탭은 `/stats` `/awards` `/roster` `/teams` 네 형제 라우트를 탭처럼 묶은 구조다.
실측 결과 두 가지 중복이 있다.

- 리더보드와 어워즈는 같은 원천(`computeLeagueStats`)과 같은 분기 필터를 쓰고 지표 7개가 겹친다.
  다른 점은 자격 기준(30% vs 60% 참여·게스트 제외)과 형태(평균 vs 누적), 어워즈 전용 부문 5개뿐이다.
- 팀 순위 페이지에는 이미 분기 칩·팀별 선수 스탯·비정규 선수 섹션이 있다.
  선수 명단 페이지의 고유 가치는 카드 정보(포지션·참석률·인증회원)와 운영자 편집 기능뿐이다.

확인된 전제(2026-09-28 사용자 답변):

1. 어워즈는 분기 끝 발표가 아니라 **상시 갱신 순위**다.
2. 포지션·참석률·인증회원 표시는 **운영진만** 보면 된다.
3. `/roster` `/awards` URL은 외부 공유한 적이 없다.

## 결정

스탯 탭을 **4개 → 2개**로 줄인다.

| 탭 | 라우트 | 내용 |
|---|---|---|
| 리더보드 | `/stats` | 기존 리더보드 + 표 모드에 「어워즈」 추가 |
| 팀 | `/teams` | 기존 팀 순위 + 팀별 선수 명단 + 비정규·게스트 + 운영자 편집 모드 |

`/awards` → `/stats?mode=awards`, `/roster` → `/teams` 로 `redirect()` 한다. 외부 공유 이력이 없으므로
내부 링크(라커룸·설정·소셜카드 등)만 바꾸고 리다이렉트는 한 줄씩만 둔다.

## 1. 리더보드 (`/stats`)

- 표 모드 칩: Basic · Shooting · Advanced · **어워즈**.
- 어워즈 모드는 지금 `awards/page.tsx` 의 부문 카드(1위 + 2·3위, 모달로 전체 후보)를 그대로 옮긴다.
  자격 요건 박스(60% 참여·게스트 제외)도 함께 옮겨 이 모드에서만 보인다.
- 데이터: 어워즈 모드 진입 시에만 `GET /api/leagues/[id]/awards?quarterId=` 호출. API는 손대지 않는다.
- 분기 칩은 공용 컴포넌트(아래 4절)로 교체. 문구는 「전체」로 통일.
- 부문 개수 문구 불일치(주석 11 · 코드 12 · 화면 「코어 8 + 특수 3」)는 코드 기준 **「코어 9 + 특수 3」** 으로 맞춘다.
- `StatGate`(401 시 회원 전용 화면)는 그대로.

## 2. 팀 (`/teams`)

화면 순서(위→아래):

1. 공용 분기 칩(공유 컨텍스트, 기본값 현재 분기)
2. 팀 순위 카드(기존)
3. 팀 전적 · 상대 전적(기존)
4. **팀별 선수**: 팀 카드마다 그 분기 정규 소속 선수 목록. 기존 「팀별 선수 스탯」 섹션을 이 자리로 쓰고,
   선수 줄은 **이름 · 등번호 · 리더 왕관 · 스탯**만 표시한다. 포지션·참석률·인증회원은 회원 화면에서 뺀다.
5. **비정규 선수**(기존 섹션 유지) · **게스트**(접이식, 기본 접힘)

운영자 편집 모드(기존 `roster` 의 편집 권한 판정을 그대로 가져옴):

- 헤더에 「명단 편집」 토글. 켜면 4·5번 섹션의 선수 줄이 편집 가능한 카드로 바뀌고,
  포지션·참석률·인증회원 표시가 이때만 나타난다.
- 옮겨오는 기능: 선수 추가, 엑셀 일괄 등록, 선수별 분기 소속 변경(팀 ↔ 비정규), 이전 분기 이어받기, 분기 관리.
- 소속 변경 API(`POST /quarters/{q}/players`)와 데이터 구조(`league_player_quarters`)는 변경하지 않는다.

## 3. 탭 목록과 레이아웃

- `src/components/league/statsTabs.ts` 의 `getStatsGroupTabs` 를 2개 항목으로 줄인다(`leaderboard`, `teams`).
- `_components/LeagueLayoutClient.tsx` 의 스탯 탭 활성 경로에서 `/awards` `/roster` 를 뺀다.
- `awards/` `roster/` 라우트 폴더는 `page.tsx` 한 줄(redirect)만 남기고 `loading.tsx` 는 삭제.

## 4. 공용 분기 칩

- 새 컴포넌트 `src/components/league/QuarterChips.tsx` 하나. props: `quarters`, `value`, `onChange`, `allLabel="전체"`.
- 값은 기존 `LeagueQuarterContext`(`useLeagueQuarter`)를 쓴다. 팀 페이지의 로컬 상태 `selectedQId` 를 이 컨텍스트로 바꾼다.
- 기존 3곳 인라인 버튼을 전부 이 컴포넌트로 교체.

## 5. 손대지 않는 것

- 통계 계산(`computeLeagueStats`, 어워즈 API, season-highs), 자격 기준(30% / 60%).
- DB 스키마. 마이그레이션 없음.
- 대회 모드(`mode='tournament'`) 화면 트리. 리그 트리만 대상.
- 팀 페이지 데이터 조회 방식(정체성 목록 API 등). 화면 조립만 바꾼다.

## 6. 검증

- `tsc --noEmit`, `verify-schema.mjs`, `verify-scoring.mjs` 통과.
- Playwright 육안: 375px · 1024px 에서 `/stats`(어워즈 모드 포함), `/teams`(회원 / 편집 모드), `/awards` `/roster` 리다이렉트.
- 확인 코드 하나: `getStatsGroupTabs` 가 2개를 돌려주고 키가 `leaderboard`·`teams` 인지.
- 기준선(미라클 득점 7114 · 선수 45) 변동 없음. 이 작업은 표시만 바꾼다.

## 7. 위험

- `teams/page.tsx` 는 이미 1518줄이다. 명단 편집 기능을 붙이면 2000줄을 넘으므로 편집 모드는
  `teams/_components/RosterEditor.tsx` 로 분리해서 옮긴다(로직 이동, 재작성 아님).
- 어워즈 모드는 `/awards` 를 즐겨찾기한 회원이 있을 수 있어 리다이렉트를 최소 한 분기는 유지한다.
