# 라이트 유저 친화 개편 — 1~3단계

근거: 실사용자 피드백 2건 + 구조 감사(`.superpowers/sdd/audit-casual-identity.md`) +
설계 플랜 아티팩트(2026-08-10).

## 사용자가 정한 것 (이 계획의 상위 제약)

1. **스크롤을 최대한 지양한다. 접이식으로 해결 가능하면 접이식.**
   — 세로를 늘리는 개선은 기본적으로 접힌 상태로 들어간다.
2. **정의만 있고 소비처가 없는 자산은 삭제한다.** 되살리지 않는다.
   → 결과적으로 "농구다움" 은 **배경 장식이 아니라 사람·팀컬러·영상**으로 낸다.
3. **홈 첫 화면은 매일 순위를 보는 회원이 주 사용자.** 순위표를 첫 화면에서 밀어내지 않는다.
4. **홈의 '리그 리더' 위젯을 전체 공개**한다(현재 승인 회원 전용).

## Global Constraints

1. **밀도 불변** — 스탯 테이블·박스스코어의 열 개수·행 높이·`tabular-nums`·sticky 첫 열·
   가로 스크롤을 건드리지 않는다. 매일 쓰는 기록 도구다.
2. **세로를 늘리지 않는다.** 새 정보는 접이식(기본 접힘) 또는 기존 여백 안에서 해결한다.
   불가피하게 늘어나면 무엇이 얼마나 늘었는지 보고한다.
3. 하드코딩 hex 금지(`--mm-*`) · **이모지 금지**(lucide-react) · 44px 터치 타깃.
4. 테마 반전 토큰 위 `#fff`/`#000`/`text-white` 고정색 금지.
5. 활성 탭 판정은 `pathname` 기준(미들웨어 slug→UUID rewrite) — `deriveLeagueBase()` 사용.
6. `.maybeSingle()` · 쿼리 error 를 빈 결과로 삼키지 말 것 · 에러에 DB 원문 노출 금지.
7. 서버 `page.tsx` 는 데이터 fetch **전에** `isLeaguePrivateGated` 조기 return.
8. `npx tsc --noEmit` · `npm run build` 통과, `node scripts/verify-schema.mjs` exit 0.
   ⚠ `verify-scoring` 은 최근 경기 기록으로 총득점이 변해 실패할 수 있다. **손대지 말 것.**
9. **스톡 사진·일러스트 도입 금지.** 이 제품엔 실제 선수 사진과 경기 영상이 있다.

## Task 1 — 숫자를 읽을 수 있게 (피드백 ①)

**핵심: 새로 만들지 않는다. 이미 있는 것을 배선한다.**
용어집 56항목과 모바일 탭 지원 툴팁(`StatHelpTooltip`)이 이미 완성돼 있고,
**소비처가 데스크톱 스탯표 1곳뿐**이다. 실사용은 모바일이 더 많다.

### 1-A. 용어 툴팁 배선
- **스탯 모바일 카드뷰** — 설명 없는 약어 12개(`PPG·RPG·ORpg·DRpg·APG·SPG·BPG·TOPG·FG%·3P%·FT%·eFG%`)
- **팀 순위**(`teams/page.tsx`) — 약어 8개 추가(`fg2_pct·ds_pct·at_ratio` 등). `StatHeader` import 자체가 없다
- **어워즈** — `3P%·eFG%`
- 기존 툴팁 컴포넌트를 그대로 쓴다. **새 툴팁을 만들지 말 것.**

### 1-B. 한글 병기
- 약어 옆(또는 툴팁 안)에 한글 풀네임. 예: `PPG` → "경기당 득점"
- **표 헤더는 좁으므로 카드뷰부터.** 표 헤더까지 넣어 열이 밀리면 안 된다(밀도 불변)

### 1-C. 좋은 방향 표시
- 지표마다 **높을수록 좋은지 / 낮을수록 좋은지** 한 눈에.
  `TOPG`(턴오버)·`PF`(파울)는 낮을수록 좋다 — 라이트 유저는 이걸 모른다
- 화살표·기호 등 **작은 표식 하나**로. 색만으로 전달하지 말 것(접근성)

### 1-D. "이 표 읽는 법" — 접이식
- 스탯/팀순위 상단에 **기본 접힌** 한 줄 안내. 펼치면 주요 지표 3~4개를 쉬운 말로
- ⚠ 사용자 제약: **접힌 상태에서 세로를 거의 안 먹어야 한다**

## Task 2 — 사람을 화면에 (피드백 ①②)

### 2-A. 홈 '리그 리더' 전체 공개 ⚠ 정책 변경
- 현재 승인 회원 전용(`StatGate`). **비로그인·미승인도 보이게** 한다.
- ⚠ 이 저장소는 2026-07-28 에 **스탯 게이팅 정책**을 세웠다:
  공개 = 박스스코어·순위표·명단 / 전용 = 시즌스탯·어워즈·하이라이트.
  이번 변경은 **홈의 리그 리더 위젯 하나만** 여는 것이다.
  **스탯 탭 전체나 다른 게이트를 건드리지 말 것.**
- 서버·클라이언트 양쪽에서 게이트를 확인하라. 화면만 열고 API 가 401 이면 빈 화면이 된다.

### 2-B. 홈 첫 화면은 순위표 유지
- 사용자 결정: 매일 순위를 보는 회원이 주 사용자.
  **기본 탭을 바꾸지 말 것.** 대신 순위표 자체를 덜 차갑게 만든다:
  - 팀 컬러를 더 분명하게(이미 색 막대가 있다 — 강화 여부 판단)
  - 세로를 늘리지 않는 선에서

### 2-C. 팀 순위 화면에 얼굴·팀컬러
- `teams/page.tsx` 는 **사진 0건**이다. 팀 컬러 스트립 + 대표 선수 얼굴을 넣는다
- 로스터의 **4:5 사진 + 팀컬러 스트립 패턴을 재사용**한다(검증된 패턴 · 새로 만들지 말 것)
- ⚠ 표 위에 얹되 **접이식**으로 — 기본 접힘 여부는 판단하고 근거를 보고

### 2-D. 박스스코어 상세 "그날의 주인공"
- 지금은 첫 화면이 곧장 `<table>`. 맨 위에 **최다 득점자 얼굴 + 한 줄**
- ⚠ **접이식 또는 한 줄 높이**로. 표가 밀려나면 안 된다

### 2-E. 사진 없는 선수 폴백
- 이니셜 폴백을 팀 컬러 기반으로 개선. 대비 4.5:1 확보(팀 색이 순백인 팀이 있다 — `--mm-*` 폴백 필요)

## Task 3 — 소비처 없는 자산 삭제 (사용자 지시)

**규칙: 소비처가 0 이면 정의도 지운다.** 되살릴 계획을 세우지 않는다.

`animate-ball-spin`(1) · `app-splash` · `announcement-prose`

- 삭제 전 **각 대상의 소비처가 정말 0 인지 직접 grep 으로 재확인**하라. 하나라도 있으면 멈추고 보고.

## 완료 기준
- 라이트 유저가 스탯/팀순위 화면에서 **약어의 뜻과 좋은 방향**을 화면 안에서 알 수 있다
- 홈 리그 리더가 **비로그인에게도** 보인다 (다른 게이트는 불변)
- 팀 순위·박스스코어에 **사람 얼굴**이 등장한다
- **세로 스크롤이 유의미하게 늘지 않았다** — 늘었다면 수치로 보고
- 소비처 0 자산이 코드·문서에서 사라졌다
- master 병합 + push
