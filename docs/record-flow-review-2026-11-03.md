# 경기 기록 프로그램 검토 — 「누구나 기록할 수 있게」 (2026-11-03)

운영진 요청: 지금은 운영자 한 명이 유일한 기록원. 기록 시간을 더 줄일 요소와, 영상을 보며 편하게
기록할 기능을 검토하고, 간단한 교육만으로 다른 회원도 기록할 수 있게 하는 방향을 찾는다.
**이 문서는 검토 결과이며 코드 변경은 없다.** 반영 여부는 운영진이 고른다.

---

## 1. 지금 구조 (비개발자용 한 장 요약)

기록 화면은 `/league/미라클/record?date=날짜` 한 곳이고, 흐름은 다섯 단계다.

| 단계 | 화면 | 지금 하는 일 |
|---|---|---|
| ① 날짜·경기 고르기 | 일정 탭 「기록하기」 → 슬롯 격자 | 영상이 올라오면 밤 11:30 자동으로 날짜·칸·영상이 깔린다. 1·2경기 팀만 저장하면 나머지 대진은 자동 |
| ② 기록 준비 | 「기록 준비」 카드 | 정규전/친선전 · 팀 · 영상(접힘) · +1(접힘) |
| ③ 선발 고르기 | 드래그 카드 | 「지난 경기와 같은 선발」 버튼 있음 |
| ④ 기록 | 왼쪽 영상(고정) + 오른쪽 입력 패드 | **선수 → 종류 → 성공/실패 → 어시스트(3초 안) → 실패면 리바운드 선수** 순서. 영상 시각이 자동으로 붙는다 |
| ⑤ 마감 | 마감 모달 | 토스트의 「N경기 기록하기 →」로 다음 경기 |

입력 패드 한 번의 기록은 평균 **3~4번 터치**(선수 1 + 종류 1 + 성공/실패 1 + 어시스트/리바운드 1).
이미 있는 편의: 성공/실패 단축키 `A`/`S`, 영상 `Space`·`←→`(5초)·`Shift+←→`(10초), 마지막 기록 「↩ 취소」,
기록 중 앞선 기록 그 자리에서 수정(`EventLogPanel`), 중단 뒤 이어 열기(12시간), 스틸→턴오버 짝 자동, 개인 반칙 표시.

### 실측 (미라클 정규전 마감 경기 303개, 2026-11-03 DB 조회)

| 항목 | 값 | 뜻 |
|---|---|---|
| 경기당 기록 | 중간값 68건 (평균 71) | 10분짜리 경기에 70번 입력 |
| 경기 하나 기록 소요 | 중간값 **8분** (7~9분) | 영상 길이 중간값 10분보다 **이미 짧다** |
| 기록 사이 간격 | 중간값 5초, 절반이 5초 미만 | 손은 쉬지 않는다 — 병목은 손이 아니라 **영상 재생 시간** |
| 9경기 하루 기록 | 90~110분, 하루에 한 번에 | 토요일 오후 2~3시 또는 밤 10~11시 |
| 성공 슛에 어시스트 기록 | 73% | 어시스트 선택 단계를 대부분 거친다 |
| 실패 슛 뒤 리바운드 기록 | 93% | 리바운드 선택 단계를 거의 항상 거친다 |
| 교체 기록 | 57건 (전체 2.2만 중) | 교체는 사실상 기록 안 함 — 출전 시간은 못 낸다 |
| 파울 기록 | 3건 | 파울도 기록 안 함 |
| 영상 시각 없는 기록 | 0% | 모든 기록이 영상 장면과 연결됨 |

**결론 하나:** 영상 10분을 8분에 기록하고 있으므로, 버튼을 더 줄여서 얻을 시간은 많지 않다.
남은 시간은 ① 영상을 **빨리 돌리는 것**, ② 공이 멈춘 구간을 **건너뛰는 것**, ③ 하루 9경기 사이의 **준비 시간**에서 나온다.
반대로 「누구나 기록」의 걸림돌은 속도가 아니라 **규칙을 아는 사람만 누를 수 있는 버튼**이다(아래 3장).

## 2. 기록 시간을 줄일 요소 (효과 큰 순)

### A. 재생 속도 버튼 — 지금 없다 ★
- YouTube 재생기는 1.25·1.5·2배속을 지원하지만 **기록 화면에 속도 버튼·단축키가 없다**(`useYoutubeRemote.ts` 에는 재생/정지·±5초만).
  유튜브 자체 메뉴로 바꿀 수는 있어도 경기마다 초기화되고, 폰에서는 메뉴가 깊다.
- 제안: 영상 아래 `1× · 1.25× · 1.5× · 2×` 버튼 + 단축키 `[`/`]`. 마지막 속도를 기억(localStorage).
  **기록 입력 중에는 자동 1배속으로 내리고 입력이 끝나면 복귀**하는 「자동 감속」을 같이 넣으면 초보도 쓸 수 있다.
- 기대: 공 없는 구간(공 넘기기·자유투 준비·아웃)이 많아 1.5배속이면 경기당 8분 → 5~6분. 하루 9경기면 **약 25분 절감**.

### B. 「다음 장면으로」 건너뛰기 — 공이 멈춘 시간 넘기기
- 득점 뒤 상대 공격이 시작될 때까지 보통 5~8초가 비는데 지금은 `→`(5초)를 눌러 넘긴다.
- 제안 1(쉬움): 득점·턴오버 저장 직후 **자동으로 3초 앞으로** 넘기는 옵션(설정에서 끄고 켤 수 있게).
- 제안 2(중간): 영상 음량 파형이나 YouTube 챕터가 없으므로 자동 감지는 어렵다. 대신 기록된 **직전 경기 기록의 평균 간격**을 쓸 필요 없이 제안 1로 충분하다.

### C. 입력 패드 「한 번에 기록」 — 터치 3~4번 → 2번
- 지금: 선수 → 「3점슛」 → 「✓ 성공」 → 어시스트 선수(또는 2초 대기). 성공/실패를 **종류 버튼에 합치면** 한 단계가 빠진다.
  예: 종류 버튼을 두 쪽으로 나눠 왼쪽 「3점 ✓」 오른쪽 「3점 ✗」, 또는 **종류를 길게 누르면 실패**.
- 어시스트 3초 자동 대기는 기록을 쉬지 않는 손에는 3초 손실이다(성공 슛 73%가 어시스트 있음 → 27%는 매번 3초를 기다림).
  제안: 대기 없이 **「어시스트 없음」을 선수 격자의 첫 칸으로** 두고, 누르지 않고 다음 선수를 고르면 그 사람이 어시스트.
- 리바운드는 93%가 기록되므로 지금 흐름(실패 → 리바운드 피커)이 맞다. 다만 **직전 슈터 팀의 리바운드(공격 리바)는 적다**(oreb 1,976 vs dreb 4,441) —
  피커에서 상대 팀(수비 리바)을 위에 크게, 같은 팀을 아래 작게 두면 눈이 덜 움직인다.

### D. 선수 버튼을 코트 위 5명만, 유니폼 번호 크게
- 지금 패드는 코트 위 선수만 보여 준다(좋다). 다만 버튼이 **이름**이다. 영상에서 보이는 것은 **등번호·유니폼 색**이므로,
  초보 기록원에게는 「번호 크게 + 이름 작게」가 영상과 바로 이어진다. 번호 없는 선수가 있으면 이름만.
- PC 에서는 숫자 키 `1~5`(왼쪽 팀), `6~0`(오른쪽 팀)으로 선수를 고르는 단축키를 두면 선수 → 종류가 키 두 번이 된다(기존 `A`/`S` 와 같은 결).

### E. 경기 사이의 준비 시간
- 9경기를 100분에 기록하면 경기당 11분인데 기록 자체는 8분 → **경기당 약 3분이 준비·마감·이동**이다(하루 25분).
- 지금도 「지난 경기와 같은 선발」·「N경기 기록하기 →」가 있다. 더 줄일 곳:
  - 마감 모달에서 「마감하고 다음 경기 바로 시작」 한 버튼(다음 경기 선발 = 그 두 팀의 직전 선발 자동 적용).
  - 승자 잔류라 1·2경기 뒤 팀은 자동인데, **선발은 매번 고른다**. 미라클은 팀당 5~6명이라 「팀 전원 선발」이 기본값이어도 된다(이미 리그에선 전원 체크 기본 — 확인만).

### F. 자동 기록(hoops-autostat) 검토 패널을 리그 기록 화면에도
- 파란날개 팀 화면에는 2026-10-19 에 영상 분석 결과(.jsonl)를 올려 **검토 후 저장**하는 패널이 있지만 **리그 기록 화면에는 없다.**
- 효과는 자동 분석의 정확도에 달린다. 지금 파일은 우리 팀 득점·파울만이라, 리그(양 팀 모두 우리 회원)에서는 **득점 후보만 미리 깔아 두고 리바운드·어시스트는 사람이 덧붙이는** 반자동이 현실적이다.
  득점은 경기당 약 35건이라 절반이 자동으로 들어오면 경기당 2~3분 절감. 단, 운영진이 영상 분석을 매주 돌릴 사람이어야 한다 — 그 사람이 또 운영자 한 명이면 병목이 옮겨 가는 것뿐이다.

## 3. 「누구나 기록」을 막는 것 — 속도보다 중요

### 3-1. 규칙을 알아야 누를 수 있는 버튼이 셋 있다
| 버튼 | 왜 어려운가 | 제안 |
|---|---|---|
| 자유투 4종(`자유투 1점`·`2점슛 파울(2점)`·`3점슛 파울(2+1)`·`앤드원`) | 미라클 자체 룰(1구 2점)을 알아야 한다. 실측: ft_2pt 470 · 앤드원 117 · 나머지 40건 | 평소엔 **「자유투」 하나**만 보이게 하고, 누르면 「2점 파울 / 3점 파울 / 앤드원」을 묻는다. 정식 1점(`free_throw`)은 고급에 숨긴다(1건뿐) |
| 2점 세부(미드·레이업·골밑) | 「골밑슛과 레이업의 차이」를 교육해야 한다 | 유지하되 패드에 **한 줄 설명**(ⓘ): 레이업=달려가서, 골밑=서서, 미드=그 외 |
| +1(플러스원)·타팀 임시 출전·비정규 추가 | 운영 개념 | 이미 접혀 있다. 「고급」 안으로 더 깊이 넣고 **기록 중 패드에선 보이지 않게** |

### 3-2. 기록원 모드 두 단계 — 「기본」과 「운영자」
- 기본 모드(새 기록원): 득점 4종 + 리바 2 + 스틸·블록·턴오버 + 자유투 1 + 취소. 쿼터·+1·슬롯·친선전 토글·영상 연동은 숨김.
- 운영자 모드(지금 화면): 전부.
- 구현은 설정 하나(`localStorage` 또는 계정 플래그)로 버튼을 가리는 것이라 작다. **데이터 구조는 바뀌지 않는다.**

### 3-3. 연습 경기 — 저장 안 되는 「연습하기」
- 교육의 핵심은 「망칠 걱정 없이 눌러 보기」다. 제안: 지난 경기 하나를 **연습 모드**로 열어 같은 영상·같은 패드에서 기록하되
  저장은 브라우저 안에만(서버로 안 보냄). 끝나면 **실제 기록과 비교해 「일치 92%」** 처럼 보여 준다.
  실제 기록이 모두 영상 시각을 갖고 있어(0% 누락) 비교가 가능하다 — 이 자산을 교육에 쓰는 것이다.
- 이게 있으면 교육 = 「연습 경기 2개 해 보고 90% 넘으면 기록원」으로 끝난다. 사람이 옆에 앉아 가르칠 필요가 없다.

### 3-4. 기록 중 화면 안 2분 가이드
- 기록 화면 첫 진입(기기당 한 번)에 **4장짜리 안내**: ① 선수 누르고 ② 무엇을 했는지 ③ 들어갔나 ④ 틀리면 ↩.
  지금은 도움말이 전혀 없다(`record/` 아래 도움말·튜토리얼 문자열 0건).
- 패드 상단에 지금 단계를 말로: 「**누가** 했나요?」 → 「**무엇**을?」 → 「**들어갔나요?**」 → 「**누가 리바운드?**」. 이미 상태값은 다 있어서(pendingShot·awaitingRebound 등) 글자만 붙이면 된다.

### 3-5. 혼자가 아닌 둘 — 「쿼터 나눠 기록」
- 한 경기를 두 사람이 1·2쿼터 / 3·4쿼터로 나누어 각자 폰에서 기록할 수 있다(이미 쿼터 단위 저장·영상이 있다).
  막는 것은 **같은 경기를 두 기기가 동시에 열었을 때 점수줄이 상대 기록을 안 반영**하는 점 — 저장 뒤 `fetchLiveScore` 를 하므로 거의 되지만,
  「다른 기록원이 이 경기 N쿼터 기록 중」 표시가 없다. 작은 표시 하나면 하루 9경기를 세 사람이 3경기씩 나눌 수 있다.

### 3-6. 틀려도 되는 안전망 — 마감 전 자동 점검
- 마감 모달에 **자동 점검 3줄**: ① 점수가 영상 점수판과 맞나(직접 입력해 대조) ② 실패 슛 중 리바운드 없는 것 N건 ③ 성공 슛 중 어시스트 없는 것 N건.
  새 기록원은 「내가 잘 했나」를 알 수 없어 불안해한다. 숫자로 보여 주면 교육이 줄어든다.

## 4. 추천 순서 (작은 것부터)

| 순서 | 항목 | 크기 | 효과 |
|---|---|---|---|
| 1 | **재생 속도 버튼 + 입력 중 자동 감속**(2-A) | 작음(반나절) | 하루 20~25분 절감, 운영자 본인에게 즉시 |
| 2 | **자유투 4종 → 「자유투」 하나 + 질문**(3-1), 단계 안내 문구(3-4) | 작음 | 초보 진입 장벽의 절반 |
| 3 | **기본/운영자 모드**(3-2) + 첫 진입 4장 안내 | 중간 | 「간단한 교육」을 화면이 대신 |
| 4 | **연습 모드 + 일치율**(3-3) | 중간~큼 | 교육 없이 기록원 검증 |
| 5 | 성공/실패 합치기·어시스트 대기 제거(2-C), 번호 크게·숫자 단축키(2-D) | 중간 | 터치 1~2번 절감, 운영자 숙련자용 |
| 6 | 마감 자동 점검(3-6) · 쿼터 나눠 기록 표시(3-5) | 작음 | 둘 이상 기록원 운영의 기반 |
| 7 | 자동 기록 패널 리그 확장(2-F) | 큼 · 외부 도구 의존 | 정확도 확인 뒤 |

### 운영진 확인이 필요한 것
- 교체·파울은 **의도적으로 안 기록**하는 것인지(실측 57건·3건). 안 하는 것이 맞다면 기본 모드에서 「파울」 버튼을 빼도 된다(지금은 패드에 있다).
- 새 기록원은 **어드민 권한**을 받는가, 아니면 「기록원」 역할을 따로 만드는가. 지금은 기록 = 어드민 권한이라 명단·설정도 같이 열린다.

### 5-2. 제안과 이유 — 전후 비교

#### ① 성공/실패를 슛 종류 버튼에 합친다 — 가장 큰 절감 ★

- **지금**: 「3점슛」을 누르면 그 자리가 「✓성공 / ✗실패」 두 칸으로 바뀐다. 슛마다 **한 번 더** 누른다(경기당 35번).
- **제안**: 슛 종류를 **두 줄**로 — 윗줄 「3점 ✓ · 미들 ✓ · 레이업 ✓ · 골밑 ✓」(초록 테두리), 아랫줄 같은 네 종류의 ✗(빨간 테두리). 한 번에 종류와 결과가 정해진다.
- **이유**: 기록원은 영상에서 슛이 들어가는 것을 보고 누르므로 **결과를 이미 안다**. 종류와 결과를 따로 묻는 것은 두 번 묻는 것이다.
  PC 의 `A`/`S` 단축키는 그대로 두어 키보드 사용자는 종전처럼 쓸 수 있다.
- **위험**: 버튼이 4 → 8개로 늘어 하나가 작아진다. 미라클 패드는 폰 폭에서 4칸이 44px 이상이므로 2줄로 늘려도 높이만 커진다(넘침 없음). 색 대신 **✓/✗ 글자**를 크게 둬서 색약 기록원도 구분되게 한다.
- **전후**: 슛 성공(어시스트) 4 → **3**, 성공(없음) 3 → **2**, 실패 4 → **3**. 경기당 **−35번(−21%)**.

#### ② 어시스트 3초 대기를 없애고 「다음 터치가 곧 답」으로

- **지금**: 성공 뒤 어시스트 선수 격자가 뜨고 3초 카운트다운. 어시스트가 없으면 3초를 기다리거나 「어시스트 없음」을 누른다(성공 슛의 27%).
- **제안**: 카운트다운을 없앤다. 격자는 뜨지만 **같은 팀 선수를 누르면 어시스트**, **그 외 아무것(상대 선수·다른 버튼)을 누르면 어시스트 없음으로 저장하고 그 터치를 다음 기록의 첫 터치로** 그대로 쓴다.
- **이유**: 득점 직후의 다음 장면은 **항상 상대 팀 공격**이다. 그래서 「같은 팀 선수를 누른다 = 어시스트」는 다른 뜻으로 읽힐 일이 없다. 기다리는 3초는 영상이 그만큼 흘러가 다음 장면을 놓치게 만드는 시간이기도 하다.
- **위험**: 어시스트를 누르려다 상대 선수를 잘못 누르면 어시스트 없이 저장된다 → 기존 「어시스트 추가」 보정 메뉴가 있어 복구 가능.
- **전후**: 터치 수는 같고(3 → 3) **경기당 약 35초 대기 제거**, 기록 리듬이 끊기지 않음.

#### ③ 리바운드 피커의 팀 순서 — 수비 팀을 위로

- **지금**: 피커가 슈터 팀(공격 리바) → 상대 팀(수비 리바) 순으로 두 묶음을 보인다.
- **제안**: 실측상 수비 리바 4,441 vs 공격 리바 1,976(69:31)이므로 **상대 팀(수비 리바)을 위에 크게**, 슈터 팀을 아래 작게.
- **이유**: 터치 수는 같지만 눈이 가는 거리와 고르는 시간이 줄어 오터치가 준다. 비용이 거의 없다.
- **전후**: 터치 4 → 4, 선택 시간 단축(측정 불가, 체감).

#### ④ PC 에서 선수·종류를 키보드로 (숙련자용)

- **지금**: 성공/실패만 `A`/`S`. 선수와 종류는 마우스.
- **제안**: 왼쪽 팀 선수 `1~5`, 오른쪽 팀 `6~0`, 슛 종류 `Q`(3점)·`W`(미들)·`E`(레이업)·`R`(골밑), 리바운드 `D`, 스틸 `F`, 턴오버 `G`. 패드의 각 버튼 모서리에 글자를 작게 표시(지금 A/S 처럼).
- **이유**: 운영자(숙련자)는 PC 에서 하루 9경기를 100분에 기록한다. 키보드는 손이 화면을 찾지 않아 영상에서 눈을 떼지 않게 한다. 초보는 그대로 터치로.
- **전후**: 터치 수는 같지만 「눈 이동 0」. 1.5배속과 합치면 숙련자 경기당 8분 → **5분 안쪽** 예상.

#### ⑤ 하지 않기로 한 것 (검토했지만 권하지 않음)
- **리바운드 피커 생략(자동 추정)**: 실패 슛의 93%에 리바운드가 찍히는데, 누가 잡았는지는 영상을 봐야만 안다. 자동으로 넣으면 틀린 기록이 늘어난다.
- **턴오버·스틸 합치기 변경**: 지금도 3번이고 짝이 자동으로 묶인다. 바꿔서 얻는 것이 없다.
- **자유투 버튼 축소**(3장 3-1): 터치가 아니라 **이해의 문제**라 「누구나 기록」 쪽 과제로 둔다(터치는 3 → 3).

## 6. 3차 반영 (2026-11-03, 운영진 캡처 피드백)

- **자유투 한 칸**: 패드에 「자유투」만 있고, 누르면 `2점슛 파울(1구·2점) · 3점슛 파울(2구·2+1점) · 앤드원(1점·바로 저장) · 정식 자유투(1구·1점)` 를 고른 뒤 O/X. 단축키 `T`.
- **단축키 배지**: 검은 바탕 흰 글자 배지로 키웠다(PC 에서만).
- **「F1」**: 오류가 아니라 **개인 파울 1개** 표시였다(옛 파울 기록 1건). 파울을 기록하지 않으므로 이제 **4개(주의)·5개(퇴장)** 부터만 보인다.
- **게스트·임시 선수 · 타팀 임시 출전**: 패드 아래에서 빼고 **「교체」 모달 안** 접힌 칸으로.
- **실시간 요약**: 패드 아래에 코트 위 선수별 `득점·리바·어시·스틸·블록·턴오버` 와 팀 합계. 기록이 저장될 때마다 갱신. 자세한 표는 종전 「박스스코어」 버튼.
- **영상 시각 기준**(운영진 질문): 종전엔 **저장되는 순간**이었다 — 슛 성공은 어시스트 선수를 고른 순간, 스틸의 짝 턴오버는 턴오버 선수를 고른 순간. 그래서 고르는 동안 영상이 흐르면 그만큼 뒤로 밀렸다.
  이제는 **첫 터치 순간**이다: 슛은 O/X 를 누른 순간, 짝 턴오버는 스틸을 누른 순간. 리바운드·블록·스틸·턴오버 단독은 그 버튼을 누른 순간(종전과 같음).
  남은 것: 「어시스트 추가」 보정(마지막 기록을 지우고 다시 넣는 방식)은 아직 다시 넣는 순간의 시각이다.

## 7. 블록 짝 기록 (2026-11-03, 운영진 질문 → 같은 날 반영)

실측(정규전 블록 352건): **89% 가 6초 안에 상대 팀의 실패 슛이 함께 기록돼 있다**(평균 간격 2.8초). 즉 지금은 한 장면을
두 번 기록한다 — ① 슈터 → 종류 X → 리바운드(4터치) ② 블로커 → 블록 → 리바운드 피커 다시(3터치) = **7터치, 리바운드 질문 2번**.
블록의 `related_player_id` 는 전부 비어 있어 「누구 슛을 막았나」는 남지 않는다.

권장 형태 — **「실패 슛 → 리바운드 피커」 안에 블록 칩**: X 를 누르면 뜨는 리바운드 피커 위에 수비 팀 선수를 「블록」 칩으로
한 줄 더 보인다. 블록이 없으면 그냥 리바운드를 고른다(터치 추가 0). 블록이 있으면 칩 한 번 → 블록 저장(시각 = 슛 시각,
`related_player_id` = 슈터) → 그대로 리바운드 선택. **7터치 → 4터치**, 리바운드 질문 1번.
스틸→턴오버처럼 「블록 먼저 → 슈터」 순서는 슛 **종류**(3점·미들·레이업·골밑)를 한 번 더 물어야 해서 5터치가 된다 — 실패 슛 쪽에서
시작하는 편이 싸다. 단독 「블록」 버튼은 그대로 둔다(슛을 안 찍은 경우용).

## 9. 자동화 (2026-11-03)

- 반영: **마감하면 다음 경기가 바로 열리고**, 선발 체크박스가 두 팀 각각의 앞 경기 선발로 **미리 체크**된다. 경기는 시작되지 않는다 — 기록원이 바뀐 1~2명만 고치고 시작한다(운영진 수정안).
- 뺀 것(운영진): 선수 버튼을 누르면 영상 일시정지 — 슛 동작에서 멈춰 누가 리바운드를 잡았는지 볼 수 없다. 자동 3초 건너뛰기 · 마감 전 자동 점검은 불필요.
