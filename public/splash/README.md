# iOS 런치 스크린(전면 스플래시) 이미지

홈 화면 아이콘 실행 시 뜨는 iOS 전용 전체화면 이미지입니다.
(안드로이드는 매니페스트 `background_color` + 아이콘으로 자동 구성 — 별도 이미지 불필요)

## 넣어야 할 파일

- **`apple-splash.png`** — PNG, 세로, **1290 × 2796 px**, 배경 `#0a0a0a`
  - 로고·팀명 등 핵심 요소는 **화면 정중앙 1000 × 1000 px 안전영역**에 배치
    (상·하 여백은 노치/홈 인디케이터/기기별 크롭 대비)

이 한 장이 `src/app/layout.tsx`의 `SPLASH_DEVICES` 모든 아이폰 해상도에 매핑됩니다.

## 픽셀 퍼펙트(선택) — 기기별 개별 파일

기기마다 딱 맞는 이미지를 쓰고 싶으면 위 마스터 1장을 준 뒤
`scripts/gen-splash`로 해상도별 파일을 자동 생성해 `layout.tsx`의 `url`을 교체하면 됩니다.
